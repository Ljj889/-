# R-006 危险操作模型外硬策略门 + 不可变审计

**当** 执行涉及危险操作（删除/迁移/写生产/发布/数据变更）时 → **易犯** 把"是否允许"交给 LLM 判断（模型内软约束，概率系统会漏）→ **护栏**：

1. **模型外硬策略门**：危险操作由引擎层策略门拦截（dev/prod 隔离、写操作需人类确认），**不依赖 LLM 自觉**——与 rule 36（数据迁移必须问用户）同源
2. **不可变审计**：所有危险操作留不可变审计日志（谁/何时/什么/结果），事后可追溯
3. **默认拒绝**：未在白名单的危险操作一律拒绝（配合 R-001 执行边界）

**与框架衔接**：方法论层 = rule 36（数据迁移/语义变更必须问用户，全权执行模式不豁免）；引擎层 = 编排 B 策略门模块（待实现）。
**来源**：OpenClaw 安全边界、个人生产踩坑（默认放行导致的事故）。
