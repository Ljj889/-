# ADR-003 设置集中入口 + 功能与设置配套

**当** 应用功能增长（顶栏入口 >7、出现"功能已有但找不到设置项"）时 → **易犯** ① 入口散落（模型/设置各开一个弹窗）；② 新功能（语音输入/通话/生图）没有对应的设置项 UI——功能能用但用户无法调整 → **决策**：

1. **设置统一到单一入口**（⚙️ 图标 + 分 tab：模型与 API / 语音 / 数据），不让功能入口无限膨胀；每个 tab 一个独立 Section 组件，遵守单文件行数上限。
2. **新增功能默认自带其设置项 UI**：凡功能有配置（音色/引擎/语言/开关），交付时必须同时交付设置入口；**共用配置要在 UI 注明**（如"朗读与通话共用此音色"），避免用户以为没生效。
3. 入口按钮给 `title` 说明"设置（模型 / 语音 / 数据）"，移动端保持可横滑不裁切。

**关联**：rule 61（效果类主观验收——音色这类设置必须让人能调到才算闭环）、rule 67（UI 交付走用户终审）。
